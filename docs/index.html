Frequently Asked Questions

자주 묻는 질문 (FAQ)

AgentHub의 핵심 기능, 런타임 격리 및 MCP 도구 연동에 대한 안내입니다.

AgentHub는 기존 에이전트 실행 도구와 무엇이 다른가요?
로컬 터미널에서 제어 없이 실행되던 에이전트와 달리, AgentHub는 에이전트 런타임, 영속 워크스페이스, MCP 도구, 모델 라우팅 및 보안 정책을 하나의 통제면(Control Plane)에서 운영합니다. 팀 단위의 권한 관리와 감사 추적을 완벽히 제공합니다.
에이전트가 작업 중 작성한 코드와 파일은 어떻게 보존되나요?
각 에이전트는 영속 워크스페이스(Persistent Workspace) 볼륨에 연결되어 작업합니다. 컨테이너가 재시작되더라도 모든 파일과 상태가 유지되며, 언제든 스냅샷(Snapshot)을 생성하여 특정 시점의 개발 상태로 롤백할 수 있습니다.
Model Context Protocol(MCP) 도구는 어떻게 연동하나요?
AgentHub는 최신 2026-07-28 MCP 사양을 기본 내장하고 있습니다. MCP 카탈로그 메뉴에서 원하는 도구(Filesystem, GitHub, PostgreSQL, Web Search 등)를 등록하고 번들로 묶어 에이전트에게 안전하게 주입할 수 있습니다.
인터넷 연결이 없는 오프라인 폐쇄망(Air-Gapped) 환경에서도 구동 가능한가요?
네, 100% 완전 독립 구동이 가능합니다. AgentHub는 단일 Go 실행 파일 내에 React 19 웹 프론트엔드 에셋을 임베딩하고 있으므로 외부 CDN 요청을 보내지 않습니다. 오프라인 망에서 PostgreSQL 16+ 컨테이너와 4개의 필수 환경변수만 설정하면 즉시 완벽하게 동작합니다.
조직 모드에서 승인(Approvals) 거버넌스는 어떻게 운영되나요?
관리자가 승인 정책을 활성화하면, 에이전트가 고위험 도구를 호출하거나 새로운 모델/워크스페이스를 생성할 때 즉시 [검토 및 승인] 대기열로 이동합니다. 팀장은 세부 실행 계획을 확인한 후 단 한 번의 클릭으로 승인하거나 반려할 수 있습니다.

Ready to deploy?

30초 만에 로컬에서 실행하기

단 4개의 환경변수로 나만의 엔터프라이즈 에이전트 런타임을 즉시 기동하세요.

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker compose up -d postgres

# 2. 필수 환경변수 설정 (정확히 4개)
export AGENTHUB_POSTGRES_DSN='postgres://agenthub:agenthub-local-database-password@127.0.0.1:55434/agenthub?sslmode=disable'
export AGENTHUB_BOOTSTRAP_ADMIN='admin'
export AGENTHUB_BOOTSTRAP_ADMIN_PASSWORD='local-development-password'
export AGENTHUB_ENCRYPTION_KEY='AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA='

# 3. AgentHub 서비스 실행
go run ./cmd/agenthub

# 4. 브라우저에서 http://localhost:8080 접속!
