영속 Workspace & CSI 스냅샷

Agent Pod가 종료되거나 재생성되어도 사용자 코드와 가상환경은 PVC에 안전하게 보존됩니다. CSI VolumeSnapshot을 통해 언제든 이전 시점으로 워크스페이스를 복구할 수 있습니다.

OpenCode & Hermes 런타임

사전 검증된 Agent 템플릿과 빌더를 통해 개발용 OpenCode 또는 자율 실행형 Hermes 런타임을 사용자 전용 격리 Pod로 생성합니다.

🔀

Multi-Agent Workflow DAG

복수의 전문 에이전트 간의 순차/병렬/Supervisor 파이프라인을 설계하고, 실행 전 순환 참조(Cycle Detection) 및 최대 호출 깊이를 엄격히 검증합니다.

🔌

MCP Fabric & Streamable HTTP

전사 MCP(Model Context Protocol) 도구 레지스트리와 번들을 관리하며, Sidecar 및 전용 StatefulSet 모드로 에이전트에 유연하게 주입합니다.

🔐

Envelope Encryption Secret Vault

개인 Credential(Git 토큰, DB 암호)은 사용자 전용 데이터 키로 암호화되며, Agent 정의에는 원문 대신 식별 참조값만 주입되어 유출을 원천 방지합니다.

📊

Control Center & 불변 감사 로그

시스템 링버퍼 로그 스트림 및 모든 사용자의 CRU 행위를 감사 추적(Audit Trail)하며, Keycloak OIDC SSO 및 2인 승인 거버넌스를 지원합니다.

⚡ 5분 빠른 시작 (Local Development)

단 4개의 환경변수만으로 오프라인 및 로컬 개발 환경을 즉시 기동할 수 있습니다.

# 1. 환경 설정 파일 복사 및 필수 부트스트랩 값 지정
cp .env.example .env

# 2. PostgreSQL 데이터베이스 컨테이너 기동
docker compose up -d postgres

# 3. React 웹 포털 및 Go 바이너리 빌드
cd web && npm ci && npm run build && cd ..
make build

# 4. AgentHub 컨트롤 플레인 서버 실행
set -a && . ./.env && set +a
./bin/agenthub

# 5. 브라우저에서 접속
open http://localhost:8080 (admin / local-development-password)
